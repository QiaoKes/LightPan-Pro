## Approved product behavior and limits

R11/R13 deliberately add destination-first owned output publication, replay safety, complete-baseline gating, durable checkpoints, 30-second overlap and restart day recovery. The reference monitor's current-day-only limitation is extended by replaying the same per-day protocol from the saved checkpoint. R12 applies task metadata modes: owned stale metadata is deleted only in cloud_primary; local_primary and bidirectional preserve it. Output emission is awaited before checkpoint success, so reference background transfer failures cannot silently advance the durable watermark.

The exercised monitor posixpatht escapeTrue grammar is implemented for folder and skim paths: dot names gain a leading backslash, existing backslashes double, and component slashes become backslash-slash. UID cache nodes retain raw names and render separately; subtitle escape=None remains raw. Inverse Cookie resolution splits escaped components, handles raw dot navigation before unescaping, and preserves literal escaped dots. The first decoded component containing slash limits the getid prefix; remaining intermediate names use nf1 directory-only listings, then a final ordinary listing. A leading slash-name component uses no getid; escaped dot/backslash parents remain eligible for full/parent getid. Raw life-event leaf validation and confined output publication retain traversal protection. This ports exercised monitor branches rather than claiming every generic SDK resolver variant. Page/offset worker behavior is mapped from concurrenttools-{iter_page,iter_offset}.dis.txt. Cleanup cancels and drains Go work on errors, whereas the Python page executor can return without waiting for in-flight requests; this lifecycle adaptation prevents background HTTP after task cancellation. Root hierarchy ensure_file=False uses Android cur1,count_folders1,show_dir1,nf1,limit7000 and omits type99, as verified from the bundled iter_file_list branch. These limitations must not be described as live or complete behavioral parity.
